# Java Loops Practice

This repository contains basic Java programs to understand looping concepts.

## 📌 Topics Covered
- For Loop
- While Loop
- Do-While Loop
- Sum of Numbers
- Multiplication Table

## 💻 Programs Included
- ForLoop.java
- WhileLoop.java
- DoWhileLoop.java
- SumOfNumbers.java
- MultiplicationTable.java

## 🚀 How to Run
1. Compile the program:
   javac FileName.java

2. Run the program:
   java FileName
